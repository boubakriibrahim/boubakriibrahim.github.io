# Agent instructions

Read `docs/SKILL.md` in full before changing this portfolio.

Non-negotiable:
- never invent metrics, clients, testimonials, roles, employers or outcomes;
- keep English and French aligned;
- preserve semantic HTML, focus states, reduced motion and responsive layouts;
- avoid generic AI aesthetics, excessive cards, glowing effects, vague marketing copy and decorative dashboards;
- keep dependencies minimal unless a dependency solves a concrete problem;
- run `npm run build` and `npm run check` before committing.
